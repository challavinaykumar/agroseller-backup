Privacy policy

AgroSeller Backup · last updated 12 November 2026

What the app does

AgroSeller Backup uploads encrypted backups of the AgroSeller shop app's database to the Google Drive of the account that signed in (the shop owner). It is used only by the owner of the AgroSeller shop app.

Google user data it uses

  • It uses only the Google Drive permission drive.file: it can create files and read, update or delete only the files it created itself. It cannot see, read or change any other file in the Drive.
  • It does not read the account's email, contacts, profile or any other Google data.

How the data is handled

  • Backups are encrypted on the shop's server before upload; Google Drive only stores the encrypted files.
  • The data is not shared with, sold to or transferred to anyone, and is not used for advertising.
  • The sign-in token is kept only on the shop's own server, to upload the backups.

Removing access

The owner can remove the app's access at any time at myaccount.google.com/permissions, and can delete the backup files from Google Drive.
