AgroSeller Backup

Private backups for the AgroSeller shop app.

AgroSeller Backup copies the AgroSeller app's daily database backups into the owner's own Google Drive. The backups are encrypted on the server before they are uploaded, and they are kept so the shop's data can be restored if the server is ever lost.

It only uses the Google Drive permission to see and manage the files it creates itself; it cannot see any other files in the Drive. It is used only by the owner of the AgroSeller shop app.
